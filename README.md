# CineVault — установщики

Здесь публикуются только готовые сборки **CineVault** — персональной медиатеки фильмов и сериалов для Windows
(библиотека с постерами, оценки, история просмотров, подборки, «Что посмотреть?» и статистика; данные хранятся
локально). Исходный код приложения закрыт.

## Установка

1. Откройте [последний релиз](https://github.com/Ssanar/CineVault-releases/releases/latest).
2. Скачайте `CineVault_<версия>_x64-setup.exe` и запустите его.
3. Установка идёт для текущего пользователя и не требует прав администратора. Нужна Windows 10 или 11 (64-бит);
   если в системе нет WebView2, установщик поставит его сам.

Windows SmartScreen может предупредить, что издатель неизвестен (у установщика нет платной подписи кода):
нажмите «Подробнее» → «Выполнить в любом случае».

Установка поверх предыдущей версии обновляет её на месте — библиотека, оценки и настройки сохраняются.

## Обновления

Приложение обновляется само. Раз в день оно проверяет этот репозиторий и, если вышла новая версия, предлагает
«Обновить» → «Перезапустить». Проверить вручную: «Настройки» → «О программе» → «Проверить обновления».
Обновления подписаны: приложение не установит файл, подпись которого не совпадает с ключом разработчика.

## Что в релизе

| Файл | Назначение |
|---|---|
| `CineVault_<версия>_x64-setup.exe` | Установщик |
| `CineVault_<версия>_x64-setup.exe.sig` | Подпись установщика для автообновления |
| `latest.json` | Описание последней версии для автообновления |
